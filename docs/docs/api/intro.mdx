## Packages & Entry Points

| Import | Platform | Description |
|--------|----------|-------------|
| `@flipova/foundation` | React Native & Web | Full library – components, layouts, theme |
| `@flipova/foundation/tokens` | Universal | Static design tokens only |
| `@flipova/foundation/theme` | Universal | ThemeProvider, useTheme, useColorScheme |
| `@flipova/foundation/config` | Universal | FoundationProvider, defineConfig |
| `@flipova/foundation/registry` | Server-side / Studio | Component & layout metadata registry |
| `@flipova/foundation/web` | Web only | DOM entry — zero React Native deps |

### 🧩 Components

`useTheme` · `useColorScheme` · `useBreakpoint` · `useAdaptiveValue` · `usePlatformInfo` · `useSafeArea`
